# מניינים קרובים

אפליקציית אנדרואיד (תומכת גם במכשירי מקשים ישנים, Android 4.4+) שמציגה
אילו מניינים מתחילים עכשיו באזור המשתמש, איזה מניין התחיל לאחרונה, ורשימה
מלאה ומפורטת של כל המניינים היום - לפי קובץ נתונים (JSON) שהמשתמש טוען.

## הרצה / בנייה

הפרויקט נבנה עם Gradle סטנדרטי, וכולל Gradle Wrapper מוכן (`gradlew`,
`gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar`) - אין צורך להתקין
Gradle בנפרד. כדי לבנות:

1. פתחו את התיקייה ב-Android Studio ותנו לו לסנכרן, או
2. הריצו `./gradlew assembleDebug` - יוצר APK תחת
   `app/build/outputs/apk/debug/`.
3. שני קובצי ה-CI (`.github/workflows/build.yml` ו-`.gitlab-ci.yml`)
   בונים APK אוטומטית בכל push. ה-GitHub Action גם מפרסם אותו כ-GitHub
   Release קבוע (בעמוד ["Releases"](../../releases), תגית `build-<מספר
   ריצה>`) - אין צורך להתחבר או להמתין ל-artifact זמני כדי להוריד APK.

## פורמט קובץ הנתונים (JSON)

האפליקציה טוענת קובץ יחיד (כפתור "טעינת קובץ מניינים" במסך "הגדרות") בפורמט:

```json
{
  "location": "מתחם הסופרים",
  "shuls": [
    {
      "name": "חניכי הישיבות - חברון",
      "nusach": "אשכנז",
      "prayers": {
        "weekday": {
          "shacharit": ["נץ החמה", "06:30"],
          "mincha": "13:15",
          "arvit": ["20:00", "21:15", "22:15"]
        },
        "friday": { "shacharit": "06:00" },
        "shabbat": { "shacharit": "08:30", "mincha": "13:30" }
      }
    },
    {
      "name": "אור לישרים",
      "nusach": null,
      "prayers": {
        "weekday": { "shacharit": "07:00", "arvit": "בזמן" }
      }
    }
  ]
}
```

- `location` (אופציונלי) - שם המתחם/האזור, מוצג ככותרת משנה במסך הראשי.
- `nusach` אופציונלי - אפשר גם `null` (יוצג כריק).
- כל שדה תפילה (`shacharit`/`mincha`/`arvit`) הוא **אופציונלי**, ולכל אחד
  שלושה סוגי ערך אפשריים:
  1. מחרוזת שעה קבועה (`"HH:mm"`, 24 שעות).
  2. מחרוזת תיאור הלכתי בלי שעה (למשל `"בזמן"`/`"בשקיעה"`) - **מוצגת רק
     בקובץ עצמו**; האפליקציה לא מחשבת זמנים הלכתיים (זריחה/שקיעה) ולכן
     מדלגת על ערכים כאלה ברשימה/בהתראות.
  3. מערך - שילוב של שעה קבועה ותיאור הלכתי (למשל `["נץ החמה", "06:30"]`,
     בכל סדר) נכנס כרשומה אחת עם השעה + התיאור כהערה (`"06:30 (נץ החמה)"`);
     מספר שעות קבועות (למשל כמה זמני ערבית) - כל אחת הופכת לרשומה נפרדת.
- יום `"friday"` (אופציונלי, בנוסף ל-`"weekday"`/`"shabbat"`) - שעות שחלות
  רק ביום שישי (למשל שחרית מוקדמת יותר); אם לא הוגדר, יום שישי פשוט לא
  יציג את אותה תפילה (לא נופל בחזרה לשעת יום חול).
- סיווג היום (`weekday`/`friday`/`shabbat`) נקבע לפי יום השבוע - במסך
  הראשי אפשר גם לעיין בימים אחרים (לא רק "היום") דרך שורת בחירת היום
  (א ב ג ד ה ו שבת).
- קובץ ה-HTML הנלווה (`יצירת-קובץ-מניינים.html`) בונה קובץ בפורמט הזה
  בלי צורך לכתוב JSON ידנית - כולל שדה מתחם, יום שישי, ותיאור הלכתי/שעות
  נוספות לכל תפילה.

## התראות

במסך "הגדרות" אפשר להפעיל עד 3 התראות יומיות בשעה קבועה - אחת לכל סוג
תפילה (שחרית/מנחה/ערבית). כל התראה מציגה את המניין הקרוב ביותר מאותו סוג
תפילה, כולל שם בית הכנסת והנוסח. ההתראות שורדות אתחול מכשיר (`BootReceiver`)
ומתוזמנות מחדש אוטומטית ל-24 שעות קדימה בכל הפעלה, כך שדיוק השעה נשמר
לאורך זמן.

מומלץ ללחוץ גם על הכפתור "ביטול חיסכון בסוללה" במסך ההגדרות - חלק
מהיצרנים (Xiaomi/MIUI, Samsung ועוד) עלולים להשהות התראות מתוזמנות בלי
זה, גם עם כל שאר ההגנות תקינות.

## יומן שינויים (Changelog)

### עדכון: תמיכה בפורמט JSON מורחב, בורר יום, ועיצוב מסכים
- **פורמט JSON מורחב**: נתמכים עכשיו שדה `location` (מוצג ככותרת משנה),
  יום `"friday"` נפרד (בנוסף ל-`weekday`/`shabbat`), `nusach: null`, וערכי
  תפילה שהם מערך (שעה+תיאור הלכתי, או כמה שעות קבועות לאותה תפילה) - ראו
  פירוט מלא למעלה. כלי ה-HTML (`יצירת-קובץ-מניינים.html`) עודכן בהתאם.
- **בורר יום במסך הראשי**: הכותרת "היום: יום חול" הוסרה (חסרת משמעות -
  משתמשים באפליקציה ממילא רק ביום חול) והוחלפה בשורת 7 כפתורים
  (א ב ג ד ה ו שבת) שמאפשרת לעיין במניינים של כל יום בשבוע, לא רק היום.
  "המניין הקרוב"/"האחרון שהתחיל" מוצגים רק כשבוחרים את היום האמיתי של
  היום (אין משמעות ל"עוד X דקות" ביחס ליום אחר).
- **"טעינת קובץ מניינים" עברה למסך הגדרות** (יחד עם בורר קובץ פנימי
  למכשירים ישנים שנוסף קודם), כדי לפנות מקום במסך הראשי. במסך הראשי
  נשארו רק "הגדרות" ו"רענון", צמודים זה לזה בשולי המסך התחתונים.
- **ערכת נושא בהגדרות**: נוספה בחירה בין "לפי המכשיר"/"בהיר"/"כהה"
  (במקום זיהוי מערכת בלבד), נשמרת ומיושמת מיד.
- **תיקון checkbox לא מוצג/חופף**: בשורות ההתראות בהגדרות, ה-checkbox
  היה משותף לרוחב עם הטקסט ("התראת שחרית") בתוך אותו widget במשקל גדול -
  בהתאם למכשיר/גודל טקסט זה גרם לחפיפה (Android 14) או להיעלמות מוחלטת
  של ה-checkbox (Android 4.4 ישן). כל שורה פוצלה ל-TextView (התווית,
  קיבוע ברוחב) + CheckBox נפרד קטן (רק הסימון, בלי טקסט משלו) + הכפתור -
  כל אחד ברוחב הטבעי שלו, בלי חפיפה.
- **צבע "המניין הקרוב"**: הטקסט היה בירוק קבוע (`colorNext`) בלי סיבה
  אמיתית - הוחלף לצבע הטקסט הרגיל של ערכת הנושא (שחור בבהיר/לבן בכהה).
  הכותרת "המניין הקרוב" מודגשת וממורכזת.
- **פורמט זמן**: "עוד X דקות" כשה-X גדול (350+) הוחלף לפורמט שעות+דקות
  קריא ("עוד שעה ו-13 דקות"), גם עבור "התחיל לפני".
- **מניינים ישנים מוסתרים**: ברשימת "כל המניינים" מניין שכבר התחיל
  ומוצג רק אם עדיין "רלוונטי" - שחרית עד 30 דקות אחרי תחילתו, מנחה/ערבית
  עד 5 דקות בלבד (במקום שיישאר ברשימה כל היום).

### עדכון: דפדפן קבצים פנימי למכשירים ישנים - לא ניתן היה לעיין באחסון
- **במכשיר Android 4.4 ישן, "טעינת קובץ מניינים" הציג רק קטגוריות מובנות
  מוגבלות (הורדות/תמונות/קול/וידאו) בלי אפשרות לעיין חופשי באחסון, וגם
  בתוך "הורדות" לא הופיעו קובצי JSON שכבר היו שם.** זה קורה כי במכשירים
  ישנים (לפני Android 10/scoped storage) אין בהכרח אפליקציית "קבצים"
  שמממשת Storage Access Framework - המערכת מציגה רק ספקי תוכן מובנים
  בודדים (למשל DownloadsProvider, שמציג רק קבצים שהורדו דרך מנג'ר
  ההורדות עצמו - לא כל קובץ שהועתק לתיקיית ההורדות).
- **הפתרון**: נוסף `FileBrowserActivity` - דפדפן קבצים פשוט מבוסס
  `File`/`Environment.getExternalStorageDirectory()`, שמופעל אוטומטית
  **רק** במכשירים עם `SDK < 29` (עדיין לפני scoped storage, כשגישה גולמית
  לכל האחסון עדיין עובדת עם הרשאת `READ_EXTERNAL_STORAGE`). במכשירים
  חדשים יותר (`SDK >= 29`) ממשיכים להשתמש בבורר המערכת הרגיל
  (`ACTION_GET_CONTENT`), שעל מכשירים מודרניים כן נותן גישה תקינה לאחסון
  דרך אפליקציית "קבצים" האמיתית של המכשיר.

### עדכון: תיקון בניית ה-CI ופרסום APK ל-Releases
- **Gradle Wrapper חסר**: `gradlew`/`gradlew.bat`/`gradle/wrapper/gradle-wrapper.jar`
  מעולם לא הועלו לריפו, למרות ששני קובצי ה-CI (`build.yml` ו-`.gitlab-ci.yml`)
  קוראים ל-`./gradlew` ישירות - כל build (כולל הרצה ידנית) נכשל מיידית
  עם "No such file or directory". נוספו הקבצים החסרים.
- **פרסום APK ל-Releases**: בעבר ה-APK היה זמין רק כ-Actions artifact זמני
  (דורש התחברות ל-GitHub, פג אחרי 30 יום). עכשיו כל push ל-`main` יוצר גם
  GitHub Release קבוע עם תגית ייחודית (`build-<מספר ריצה>`), כך שאפשר
  להוריד APK בכל שלב מעמוד ה-Releases בלי התחברות.
- `versionCode`/`versionName` מתעדכנים אוטומטית לפי מספר ריצת ה-CI (במקום
  להישאר קבועים על `1`/`"1.0"`), כך שכל APK שיוצא מקבל מספר גרסה חדש
  ועולה בלי עריכה ידנית של `app/build.gradle`.
