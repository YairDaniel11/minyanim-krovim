# מניינים קרובים

אפליקציית אנדרואיד (תומכת גם במכשירי מקשים ישנים, Android 4.4+) שמציגה
אילו מניינים מתחילים עכשיו באזור המשתמש, איזה מניין התחיל לאחרונה, ורשימה
מלאה של כל המניינים לכל יום בשבוע - לפי קובץ נתונים (JSON) שהמשתמש טוען.

## הרצה / בנייה

`./gradlew assembleDebug` יוצר APK תחת `app/build/outputs/apk/debug/`.
קובצי ה-CI (`.github/workflows/build.yml`, `.gitlab-ci.yml`) עושים את זה
אוטומטית בכל push.

## פורמט קובץ הנתונים (JSON)

נוצר בקלות עם הכלי `index.html` הנלווה. פורמט מלא:

```json
{
  "location": "השכונה שלכם",
  "coordinates": { "lat": 31.9, "lon": 34.8 },
  "shuls": [
    {
      "name": "חניכי הישיבות - חברון",
      "nusach": "אשכנז",
      "prayers": {
        "weekday": {
          "shacharit": "06:30",
          "mincha": ["שקיעה-20", "מנחה גדולה"],
          "arvit": "שקיעה+20"
        },
        "friday": { "mincha": "שקיעה-15" },
        "shabbat": { "shacharit": "08:30" }
      }
    }
  ]
}
```

- **`location`** - אופציונלי, מוצג ככותרת משנה במסך הראשי.
- **`coordinates`** - אופציונלי, נדרש **רק** אם משתמשים בזמנים יחסיים
  לשקיעה/נץ (ראו למטה). ניתן למצוא ב-Google Maps: לחיצה ארוכה על המקום
  במפה מציגה קו רוחב/אורך.
- **ימי השבוע**: `weekday` (חול, גם ימי שישי אם לא הוגדר "friday" בנפרד),
  `friday` (אופציונלי - אם לא מוגדר, יום שישי משתמש ב-"weekday"),
  `shabbat`.
- **ערך שעה** לכל אחד מ-`shacharit`/`mincha`/`arvit` יכול להיות:
  - מחרוזת שעה קבועה `"HH:mm"`.
  - **זמן יחסי לשקיעה/נץ** - `"שקיעה"`, `"שקיעה-20"`, `"שקיעה+10"`,
    `"נץ+30"` (גם באנגלית: `shkia`/`sunset`, `netz`/`sunrise`). מחושב
    מחדש **כל יום** לפי התאריך בפועל וה-`coordinates`. זהו חישוב
    אסטרונומי כללי (לא מקור הלכתי מוסמך) - מדויק לכ-1-2 דקות, מספיק
    לתצוגת "מנחה X דקות לפני השקיעה" בלוח כללי.
  - מערך של שניים - אחד מהם זמן (קבוע או יחסי) והשני תיאור הלכתי חופשי
    (כמו "מנחה גדולה" בדוגמה למעלה) - התיאור מוצג בסוגריים ליד השעה.
  - מערך עם כמה זמנים תקינים - כל אחד הופך למניין נפרד (למשל כמה זמני
    ערבית).
  - כל שדה תפילה הוא אופציונלי - אפשר להשאיר ריק מה שלא רלוונטי.

## תצוגה

מסך ראשי עם שורת ימים (א'-שבת, ניתנת לגלילה אופקית) - היום הנוכחי מודגש
באות מודגשת; היום שנבחר לצפייה מודגש בצבע. בבחירת "היום" בפועל מוצגים גם
"המניין הקרוב" ו"המניין האחרון שהתחיל"; בימים אחרים מוצגת רק הרשימה
המלאה של אותו יום. כל המסך (כולל הרשימה) נגלל כיחידה אחת, כך שהוא נגיש
במלואו גם במכשירי מקשים עם מסך קטן.

## זמני היום

כפתור "זמני היום" במסך הראשי פותח מסך נפרד עם עלות השחר, הנץ, סוף זמן
קריאת שמע/תפילה (גר"א), חצות, מנחה גדולה/קטנה, פלג המנחה, שקיעה וצאת
הכוכבים - מחושבים מחדש כל יום. המיקום נלקח מ-`coordinates` בקובץ
המניינים שנטען, או שאפשר להזין קואורדינטות ידנית ישירות במסך הזה (נשמר
במכשיר, בלי תלות בקובץ). זהו חישוב אסטרונומי כללי (ראו הבהרה במסך עצמו) -
לא תחליף לפסיקה הלכתית מוסמכת.

## התראות

עד 3 התראות יומיות בשעה קבועה (שחרית/מנחה/ערבית), עם דיאלוג שעה מותאם
אישית (לא תלוי בגרסת אנדרואיד). שורדות אתחול מכשיר ומתוזמנות מחדש
אוטומטית מדי יום. מומלץ ללחוץ גם על "ביטול חיסכון בסוללה" במסך ההגדרות.

## טעינת קובץ

במכשירים מודרניים (Android 10+) נפתח בורר הקבצים הרגיל של המערכת.
במכשירים ישנים יותר נפתח דפדפן קבצים פנימי שמתחיל ישר משני קיצורי דרך -
"אחסון פנימי" ו"כרטיס זיכרון" (אם קיים) - בלי צורך לנווט מהשורש הכללי של
המכשיר.
